# Social Media Reputation Monitoring Using R and Sentiment Analysis

## 📌 About the Project

Social media platforms generate a large amount of user-generated content every day. Analysing this data manually is difficult and time-consuming.

This project focuses on monitoring social media reputation using **R and sentiment analysis**. The system analyses social media posts to understand sentiment, identify frequently occurring keywords, analyse negative/complaint-related content, and provide an overall reputation indicator.

## 🎯 Objectives

- Analyse social media text data
- Perform text cleaning and preprocessing
- Analyse positive, negative, neutral, and irrelevant sentiment
- Apply Bing Lexicon-based sentiment analysis
- Identify frequently occurring keywords
- Analyse keywords in negative tweets
- Calculate a social media reputation indicator
- Visualize the results using an interactive R Shiny dashboard
